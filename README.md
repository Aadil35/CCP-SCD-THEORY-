# CCP Project – Aadil Jamali

## Description

This Java project was created for the CCP assignment. It includes:
- A `ReservationManager` class with a `cancelReservation(int)` method that uses defensive programming principles.
- A `ReportGenerator` class to demonstrate a code smell (long method) and its refactoring using the Extract Method technique.
